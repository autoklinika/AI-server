Import nowych pozycji

Maks. 1 MB / 1000 wierszy. Jeden wiersz = nowy produkt, jedna istniejąca lokalizacja i stan. Konflikty numerów, nazw/modeli lub HW/SW blokują cały import. XLSX wymaga opcjonalnej biblioteki na serwerze.

W szablonie: format = magazyn-new-v1, kind = ecu/part, quantity = całkowita ≥ 0. ECU: new/used oraz working/faulty/unknown; elektronika: na/na. brands_json i numbers_json: tablice JSON lub puste. Szczegóły w README.
